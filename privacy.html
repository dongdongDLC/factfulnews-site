개인정보처리방침

시행일 2026-10-25

1. 이 앱이 하는 일

Factfulnews 앱은 채널 운영자 본인의 YouTube 채널에 직접 만든 영상을 올리고, 그 영상의 공개 범위를 바꾸는 데에만 Google OAuth 를 사용합니다. 운영자 외의 사용자는 이 앱에 로그인하지 않습니다.

2. 수집하는 정보

이 앱은 시청자나 다른 사용자의 개인정보를 수집하지 않습니다. 운영자 계정의 OAuth 토큰은 운영자의 비공개 저장소와 실행 환경에만 보관되며, 영상 업로드와 공개 범위 변경 외의 목적으로 쓰지 않습니다.

3. 제3자 제공

어떤 정보도 제3자에게 판매하거나 제공하지 않습니다. Google API 서비스에서 받은 정보의 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

4. 보관과 삭제

운영자는 언제든지 Google 계정의 「서드 파티 앱 및 서비스」에서 이 앱의 접근 권한을 취소할 수 있으며, 취소하면 토큰은 더 이상 쓸 수 없습니다.

5. 문의

이 방침에 관한 문의는 이 사이트의 GitHub Issues 로 남겨 주십시오.
